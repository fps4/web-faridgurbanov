### Problem Context
Marketing teams needed many microsites in English, Dutch, German, and French. Handoffs to developers slowed each update, and copying pages into multiple tools caused layout drift. We wanted one stack that let non-engineers add copy, drop in media, and preview translations without waiting for a release train.
