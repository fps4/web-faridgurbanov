# Decisions (ADRs)

Architecture decision records. Numbers are repo-local, zero-padded, sequentially assigned
(`0001-*`). Sections: **Context, Decision, Consequences**. An ADR is immutable once
accepted — write a superseding ADR rather than editing one.
