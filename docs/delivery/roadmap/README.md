# Roadmap

Milestones for the build. Each milestone flows `open -> closed`.

| Milestone | Goal | Status |
|---|---|---|
| [M0 — Credibility foundation](m0-credibility-foundation.md) | Bilingual static site establishing architect credibility; training as a CTA stub | open |
| [M1 — Training-forward](m1-training-forward.md) | Flip to training-forward home + full Training section + EU AI Act page | superseded by ADR-0010 |

The positioning sequencing (training-forward *target*, credibility-first *first ship*) was locked
in [ADR-0003](../../design/decisions/0003-single-site-training-forward-positioning.md), which
[ADR-0010](../../design/decisions/0010-the-site-has-one-job.md) supersedes: the site has one job
and is no longer training-forward. Backlog
epics and stories live under [`../backlog/`](../backlog).
